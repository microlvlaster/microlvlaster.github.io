Omarchy install

Sets up a fresh Omarchy machine. Run in a terminal:

curl -fsSL microlvlaster.github.io/boot.sh | bash

Preview without changing anything:

curl -fsSL microlvlaster.github.io/boot.sh | bash -s -- --dry-run

The script installs the GitHub CLI, asks you to log in to GitHub, downloads the (private) install repo and runs it. Read the script first.
